Support

EZ Metronome is free and open source software provided as-is, with no warranty or guaranteed support response time.

Getting Help

For questions, bug reports, or feature requests, use the project repository at github.com/timsporcic/ez-metronome. GitHub issues are the preferred place to report reproducible problems or discuss improvements.

Before Reporting an Issue

  • Confirm that you are using the latest available release.
  • Include your macOS version and EZ Metronome version.
  • Describe what happened, what you expected, and the steps needed to reproduce the issue.
