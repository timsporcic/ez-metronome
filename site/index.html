Simple controls for steady practice.

EZ Metronome is intentionally compact and open source: adjust the tempo, pick a preset, and start playing. The interface is fixed-size and native, so it feels like a small instrument utility instead of a browser tab.

  • 30-300 BPM with accelerating press-and-hold tempo nudges.
  • Quick presets for common practice tempos.
  • Spacebar start/stop plus arrow-key tempo changes.
  • Optional accented first beat for four-beat groups.

Download the free macOS build.

EZ Metronome is free and open source. The installer is tracked in the project repository under site/dist/EZMetronome-1.0.1.dmg for quick access without building from source.
